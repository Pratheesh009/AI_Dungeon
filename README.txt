AI DUNGEON - AI LAB GAME
=========================

1. Open this folder in VS Code.
2. Open Terminal in VS Code.
3. Install pygame:

   pip install pygame

4. Run:

   python main.py

Controls:
- Arrow keys / WASD : Move
- SPACE             : Run/display the AI search analysis
- R                 : Restart current level
- 1,2,3,4,5         : Jump to a level
- Level 5:
    A = Attack
    D = Defend
    H = Heal
- ESC               : Quit

AI concepts demonstrated:
- Breadth First Search (BFS)
- Depth First Search (DFS)
- A* Search
- Hill Climbing
- Constraint Satisfaction Problem (CSP)
- Logical reasoning / constraints
- Minimax game playing
- State-space search visualization
